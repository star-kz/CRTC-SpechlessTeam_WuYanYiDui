# 文档索引与编写规范

本目录存放「无言以对战队」CRTC2025 备赛的全部过程文档，依据《2025CRTC参赛手册 v1.5》4.3 节要求组织：

- **格式**：Markdown（.md）。
- **组织方式**：按机器人设计进度完成时间点从早到晚排列（文件名前缀编号即时间顺序）。
- **板块结构**：以单个机器人功能为一个板块，每个板块 = **具体功能（H2 标题）+ 功能描述与开发历程（正文）**；每篇文档由若干上述板块组成。

## 板块编写模板

每个功能板块按如下格式编写：

```markdown
## 功能名称

**完成时间**：YYYY-MM-DD

**功能描述**：该功能是什么、预期达到什么效果。

**开发历程**：构思 → 方案选型（为什么这样做）→ 实现过程 → 遇到的难点与解决方案 → 迭代优化。可附图片、代码片段、测量数据等。
```

> 提示：评估等级强调「为什么这样做」（技术选型对比、难点与解决方案、迭代优化过程），编写正文时应重点记录这些内容。
