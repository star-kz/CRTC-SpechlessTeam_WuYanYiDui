## 联调中解决掉的问题

按踩坑顺序记，细节分散在 04、05 各篇里：

1. PS2 手柄连不上接收器——按配对键重新配对解决；
2. 两块主控板共用一个接收器冲突——舵机和运动控制并到同一块板；
3. 手柄反复失灵——代码结构、接线、电压、数据地址多个问题叠加，逐个排查，最后靠重构电路排布（降压供控制、直连供电机舵机）根治；
4. 电机接线虚接——全部改焊接；
5. 线束杂乱难排查——每根线编号。
