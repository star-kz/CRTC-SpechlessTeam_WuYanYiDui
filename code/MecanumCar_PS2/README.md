# MecanumCar_PS2

整车固件，主控是官方发的 STM32F103C8（bluepill），Arduino 框架，PlatformIO 工程，ST-Link 烧录。没有用别人的开源库，PS2 协议、麦轮解算、舵机调度都是自己写的。

## 目录

```
src/main.cpp     主循环：40ms 一个控制周期，读手柄、解算麦轮、更新机械臂
lib/PS2/         PS2 手柄驱动：GPIO 模拟时序，PA4-DAT / PA5-CMD / PA6-CS / PA7-CLK
lib/Motor/       4 路电机驱动 + 麦轮运动学解算
lib/Arm/         5 舵机机械臂：角度目标更新 + 轮询刷新
platformio.ini   工程配置（bluepill_f103c8 + stlink）
```

## 几个实现要点

- **摇杆到车速**：死区 ±6 之内当 0，低速段映到 PWM 80，再线性拉满 255，两段线性拼接，低速不窜、高速够用。
- **电机最小占空比 90**：占空比低了电机只响不动，直接从 90 起步。
- **斜坡限速**：目标速度乘 0.7 逐步逼近，手柄猛推时车是加速上去的，不是蹿出去的。
- **横移后轮衰减**：实测横移时后轮比前轮劲大，后轮乘 60%。
- **舵机分时刷新**：每 4ms 只刷一个舵机，5 个轮着来，避免同时驱动拉低电压。
- **舵机步进预算**：一个控制周期内 5 个舵机的总步进量限制在 80（0.1 度为单位），动作平滑也护电源。
- **START 键回中**：所有舵机回 90° 初始位。

## 已知问题

质量分布不平衡，车走不了直线；4 个电机同样占空比转速不一致。目前靠软件斜坡和限幅缓解，机械上还在调配重。
